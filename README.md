# InternNova – Week 4: File Handling & Mini Python Project

This repository contains my Week 4 internship assignment for the InternNova Python Programming Internship.

The main topics covered in this week are File Handling, Exception Handling, Python Libraries, and Mini Project Development.

## Tasks Completed

### Task 1 – File Handling

In this task, I practiced basic file handling operations in Python.

The task includes:

- Creating a text file
- Writing data into a file
- Reading data from a file
- Appending new data
- Displaying the updated file content

File used:

`student.txt`

Python file:

`task01.py`

- Handling division by zero

- Displaying meaningful error messages

`task02.py`

### Task 3 – Python Libraries

In this task, I practiced using built-in Python libraries.

The libraries used are:

- `random` – to generate a random number
- `math` – to calculate the square root of a number
- `datetime` – to display the current date and time

Python file:

`task03.py`

### Task 4 – Mini Python Project

For the mini project, I developed a **Student Management System** using Python.

The system allows the user to:

- Add a student
- View students
- Search for a student
- Delete a student
- Save student data
- Load previously saved student data
- Display the current date and time

The project also includes input validation and exception handling.

Python file:

`task04.py`

Student data is stored in:

`students.txt`
